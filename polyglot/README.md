# Polyglot implementations

Parallel implementations of **filecarve** (Carve and recover files from raw disk images and memory dumps by signature — fast, dependency-light forensics triage.) across 9 languages, for reference and cross-language benchmarking.

- `python/` — python implementation
- `go/` — go implementation
- `rust/` — rust implementation
- `typescript/` — typescript implementation
- `c/` — c implementation
- `cpp/` — cpp implementation
- `java/` — java implementation
- `ruby/` — ruby implementation
- `csharp/` — csharp implementation
